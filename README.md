# 🍽️ Zomato Data Analytics Project

---

## 🔍 Project Overview
This project focuses on analyzing Zomato restaurant data to uncover meaningful insights about customer preferences, pricing, ratings, and location-based trends.

The goal is to transform raw data into interactive dashboards and visualizations using multiple tools, enabling better understanding and data-driven decision-making.

---

## 🎯 Objectives
- Clean and preprocess raw dataset  
- Perform exploratory data analysis (EDA)  
- Analyze restaurant ratings, cost, and locations  
- Build interactive dashboards for visualization  
- Extract actionable business insights  

---

## 🛠️ Tools & Technologies
- **MySQL** – Data querying and analysis  
- **Excel** – Data cleaning and preprocessing  
- **Power BI** – Interactive dashboard creation  
- **Tableau** – Advanced data visualization

## 📊 Key Features
- Interactive dashboards with filters and drill-down  
- Analysis of ratings, pricing, and locations  
- Comparison of restaurant performance  
- Visualization of customer trends and preferences  

---

## 📈 Insights Generated
- Higher cost does not always mean better ratings  
- Certain locations have higher restaurant density  
- Online delivery impacts customer ratings  
- Customer preferences vary across different regions
